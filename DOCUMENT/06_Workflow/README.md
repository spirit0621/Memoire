# 📁 06 - Workflow

Ce dossier documente de manière visuelle (diagrammes) les différents flux de l'application, tant du point de vue de l'utilisateur final que du processus de développement.

### Contenu

#### 1. 📂 flux/ (Parcours Utilisateurs)
Contient les diagrammes de séquence modélisant les actions des utilisateurs avec le système.
- `01_auth_workflow.md` : Connexion et routage.
- `02_generation_paie_workflow.md` : Génération d'une fiche (RH).
- `03_gestion_employes_workflow.md` : Création/Modification d'employés.
- `04_consultation_employe_workflow.md` : Téléchargement des fiches.

#### 2. 📂 processus/ (Flux de Développement)
Contient les processus techniques pour assurer la qualité du code.
- `01_git_branching_process.md` : Workflow GitFlow pour les branches.
- `02_code_validation_process.md` : Processus de Pull Request et CI.
- `03_versioning_process.md` : Mise en production et SemVer.
